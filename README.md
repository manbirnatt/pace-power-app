# Pace & Power

An offline-first workout app for an 8-week fast-bowling gym program.

- `program.js` holds the exercises. Change it here, and the app picks up the change the next time it opens online.
- Workout logs are **not** stored in this repo. They live on the device and sync to a separate private repo (`log.json`).
- Hosted with GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
